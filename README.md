# Plataforma de Estudos

Controle do edital, cronômetro de estudo e acompanhamento de desempenho.

**Acesse:** https://g4brielpeixoto.github.io/plataforma-estudos/

- **Edital:** disciplinas e tópicos, cadastrados um a um ou colados em lote; cada tópico tem check de concluído.
- **Estudar:** cronômetro, timer e pomodoro; ao salvar, o tempo vai para o histórico.
- **Histórico:** estudos agrupados por dia, com Tempo de estudo, Desempenho e Progresso no edital.
- **Início:** versículo do dia, indicadores, gráficos e pontos de atenção.
- **Usuários:** cadastro só por convite do usuário master.

## Rodar localmente

```bash
npm install
npm run dev
```

O deploy é automático: cada push na `main` publica no GitHub Pages.

Detalhes técnicos em [CLAUDE.md](CLAUDE.md).
